# Chrome and Edge browser selection

Restart the app after updating. In AI Studio, choose Browser under Image provider & browser setup. In Animate, choose Browser in Animation mode. Select Microsoft Edge, then use Login (once) to sign in and exit that dedicated browser before generation.

Chrome remains the default. Its existing login folders and ports are unchanged. Edge uses separate profile folders and connection ports; the same named account needs its own first sign-in in Edge. Browser choice is saved in drafts, projects and queued job payloads, including Excel batch settings. Retry uses the queued job's saved browser; to switch browsers, select Edge and start the desired stage again.

Local scenes and checkpoints are retained when switching. The same Flow project is reused, so sign into an account that can access it. No cookies are copied between browsers. Provider unusual-activity checks still pause generation.
